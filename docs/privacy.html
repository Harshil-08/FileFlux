Privacy Policy

FileFlux Discord Bot · Last updated: July 9, 2026

Overview

FileFlux ("the Bot") is a Discord bot that converts files between formats using slash commands. This policy explains what data the Bot processes and how it is handled.

Data We Process

File attachments (during conversion only)

When you use /convert and upload a file:

  • The file is downloaded temporarily to perform the conversion.
  • The converted file is sent back to you in Discord.
  • Both the original and converted files are deleted from our servers immediately after the conversion completes or fails.

We do not store, archive, or share your files.

Interaction metadata

While you complete a conversion (select a format), we temporarily keep:

  • A reference to your uploaded attachment
  • The detected file extension
  • A timestamp (expires after 15 minutes)

This data exists only in memory and is not written to a database.

Data We Do NOT Collect

  • Chat messages or message content
  • Server member lists, roles, or nicknames
  • User presence, status, or activity
  • Persistent user or server identifiers
  • Analytics or tracking data

Third Parties

  • Discord — Files are uploaded and downloaded via Discord's CDN. Discord's Privacy Policy applies to data on their platform.
  • Hosting provider — The Bot runs on a server we operate. No user data is persisted on disk beyond temporary conversion files, which are deleted immediately.

AI / Machine Learning

The Bot does not use message content or uploaded files to train machine learning or AI models. File conversion uses standard libraries (Sharp, LibreOffice, pdf2docx) for format transformation only.

Data Retention

  • Temporary files: deleted immediately after each conversion
  • In-memory job data: automatically deleted after 15 minutes
  • Long-term retention: none — we do not retain any user data

Your Rights

Because we do not store personal data, there is typically nothing to access, correct, or delete on our side. If you have questions, please open an issue on GitHub.

Children

The Bot is not directed at children under 13. We do not knowingly collect data from children.

Changes

We may update this policy from time to time. The "Last updated" date at the top of this page will reflect any changes.
